# План реализации AIOWA

Состояние на 06.11.2026 (выпуск 0.2.8). Порядок — тот, в котором идёт работа; каждый пункт закрывается
проверкой на реальном ящике и коммитом в `main`.

## Сделано

- **Ядро чтения без UI** — Cargo-воркспейс, протокол OWA JSON (спайк), SQLite с FTS5,
  синхронизация всех почтовых папок, тела и вложения с извлечением текста, беседы, поиск с
  операторами, CLI `aiowa`.
- **Окно** — Tauri 2 + Svelte 5: дерево папок, список бесед, область чтения в изолированном
  фрейме, поиск, синхронизация из окна (кнопка, автозапуск, раз в 2 минуты, одна папка с кнопки).

1. **Тела по требованию, вложения, картинки cid** — догрузка старых писем при открытии, открытие и
   сохранение вложений с меткой зоны, инлайновые картинки из кэша, внешние ссылки в браузере.
2. **Действия с письмами** — прочитано/непрочитано, флаг, перенос, удаление (в «Удалённые» и
   навсегда), контекстное меню, клавиши, автопометка прочитанным; оптимистичное применение с откатом.
3. **Композер** — новое письмо, ответить, ответить всем, переслать; получатели с автодополнением,
   редактор, вложения, подпись из OWA, черновики на сервере.
4. **Календарь, просмотр** — FindItem с календарным окном, кэш событий в базе, мини-календарь,
   виды день / рабочая неделя / неделя, карточка события с участниками.
5. **Мгновенные обновления и уведомления** — длинный опрос ev.owa2 вместо таймера, уведомления
   Windows о новой почте, счётчик непрочитанных.
6. **Календарь, вторая часть** — создание и правка встреч, ответ на приглашения из письма,
   напоминания, вид «месяц».
7. **Мелочи чтения и действий** — мультивыбор и массовые действия, окно отмены после удаления и
   переноса, архив, перетаскивание в папки, создание и переименование папок, черновики,
   Reply-To при ответе, предпросмотр вложений, печать.
8. **Адресная книга** — справочник организации в автодополнении (FindPeople), карточка контакта
   (ResolveNames).
9. **Настройки и первый запуск** — мастер подключения (сервер, логин, пароль с проверкой входа,
   глубина загрузки тел), `config.json` и пароль в диспетчере учётных данных Windows; окно
   настроек (Ctrl+,): смена пароля, «забыть учётную запись», глубина тел, интервал
   синхронизации, автопометка, уведомления, подпись, тема, кэш и лимит вложений.
10. **Сборка и распространение** — установщик NSIS для текущего пользователя (русский, без прав
    администратора, загрузчик WebView2), знак AIOWA в иконке и окне, светлая тема, один экземпляр
    приложения, подпись через `scripts/sign.ps1` по сертификату из переменных окружения;
    автообновление позже.

11. **Тесты и CI** — фейковый сервер OWA по снятым формам протокола и интеграционные тесты
    настоящего транспорта по HTTP (вход, синхронизация, запись, отправка, истечение и лимит
    сессий, гонки повторного входа), GitHub Actions (svelte-check, clippy без предупреждений,
    продакшн-контекст Tauri, все тесты), чистка clippy. По пути исправлены утечка сессии при
    повторном входе и отключение Reply-To от разового сбоя.
12. **Безопасность по итогам опросника** — CSP окна, запрет навигации, CORS протокола вложений
    только для окна, браузерные клавиши WebView2 выключены и повторная загрузка окна отменяется,
    журнал в файл с политикой без содержимого писем, адресов, имён вложений и токенов сессии,
    cookies только в памяти, таблица горячих клавиш с защитой от действий за открытым окном.

## Известные ограничения

- Браузерные клавиши WebView2 выключены (чтобы F5 и Ctrl+R не перезагружали окно даже из
  предпросмотра PDF): масштаб Ctrl+плюс/минус и поиск по странице Ctrl+F недоступны.
- Установщик не подписан, пока не задан сертификат (`AIOWA_SIGN_THUMBPRINT` или `AIOWA_SIGN_PFX`):
  SmartScreen покажет «Неизвестный издатель».

- Удалённые и нежелательная почта синхронизируются только после того, как их один раз
  синхронизировали с кнопки на папке («Черновики» входят в набор по умолчанию с п. 7).
- Раскрытие списков рассылки недоступно: `ExpandDL` в OWA JSON на этом сервере не реализован
  (HTTP 500 «Метод или операция не реализована», § 5l); окно прячет «Развернуть».
- Отдела нет в подсказках справочника (`persona:Department` сервер отвергает), он есть только в
  карточке контакта (ResolveNames).
- Печать письма вживую не проверялась (диалог принтера), только сборка.
