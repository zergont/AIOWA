# План реализации AIOWA

Состояние на 23.10.2026. Порядок — тот, в котором идёт работа; каждый пункт закрывается
проверкой на реальном ящике и коммитом в `main`.

## Сделано

1. **Ядро чтения без UI** — Cargo-воркспейс, протокол OWA JSON (спайк), SQLite с FTS5,
   синхронизация всех почтовых папок, тела и вложения с извлечением текста, беседы, поиск с
   операторами, CLI `aiowa`.
2. **Окно** — Tauri 2 + Svelte 5: дерево папок, список бесед, область чтения в изолированном
   фрейме, поиск, синхронизация из окна (кнопка, автозапуск, раз в 2 минуты, одна папка с кнопки).
3. **Тела по требованию, вложения, картинки cid** — догрузка старых писем при открытии, открытие и
   сохранение вложений с меткой зоны, инлайновые картинки из кэша, внешние ссылки в браузере.
4. **Действия с письмами** — прочитано/непрочитано, флаг, перенос, удаление (в «Удалённые» и
   навсегда), контекстное меню, клавиши, автопометка прочитанным; оптимистичное применение с откатом.
5. **Композер** — новое письмо, ответить, ответить всем, переслать; получатели с автодополнением,
   редактор, вложения, подпись из OWA, черновики на сервере.

## В работе

4. **Календарь, просмотр дня и недели** — FindItem с календарным окном, кэш событий в базе,
   мини-календарь, виды день / рабочая неделя / неделя, карточка события с участниками.

## Дальше, до передачи на обкатку

5. **Мгновенные обновления и уведомления** — длинный опрос ev.owa2 вместо таймера, уведомления
   Windows о новой почте, счётчик непрочитанных.
6. **Календарь, вторая часть** — создание и правка встреч, ответ на приглашения из письма
   (принять, под вопросом, отклонить), напоминания, вид «месяц».
7. **Мелочи чтения и действий** — мультивыбор и массовые действия, окно отмены после удаления и
   переноса, архив, перетаскивание в папки, создание и переименование папок, автосохранение
   черновиков и их открытие из «Черновиков», Reply-To при ответе, предпросмотр вложений, печать.
8. **Адресная книга** — автодополнение из глобального списка адресов Exchange (ResolveNames /
   FindPeople), карточка контакта.
9. **Настройки и первый запуск** — окно настроек вместо переменных окружения (сервер, логин,
   пароль, окно загрузки тел, подпись, автопометка), мастер первого запуска.
10. **Сборка и распространение** — установщик NSIS, иконка, светлая тема, подпись установщика;
    автообновление позже.
11. **Тесты и CI** — фейковый Exchange на снятых формах протокола, GitHub Actions (cargo test,
    svelte-check), чистка предупреждений clippy.
12. **Безопасность по итогам опросника** — хранение сессии, политика журналов без содержимого
    писем, таблица горячих клавиш с защитой от действий за открытым диалогом.

После п. 12 — установка на рабочее место автора, обкатка, обсуждение следующих этапов.

## Потом, по концепции

13. **ИИ-слой, этап 2** — поиск на естественном языке, «Совет» при ответе, шлюз моделей.
14. **ИИ-слой, этап 4** — агент с интернетом и корпоративными документами, обезличивание со
    ссылками (см. `pseudonymization-design.md`).

## Известные ограничения

- Reply-To при ответе игнорируется: заголовок не хранится в базе (закрывается в п. 7).
- Служебные папки (черновики, удалённые, нежелательная) синхронизируются только после того, как
  их один раз синхронизировали с кнопки на папке.
- Отмены удаления нет, письмо возвращается через «Переместить…» (п. 7).
