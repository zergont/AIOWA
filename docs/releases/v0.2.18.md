Почта для ИИ-агентов: AIOWA умеет работать MCP-сервером.

- Агент на этом компьютере — Claude Desktop, Claude Code — может сам искать и читать почту из локальной базы AIOWA: письма и беседы целиком, папки, вложения, календарь, контакты. «Найди, что писали про поставку», «сведи переписку в таблицу», «что у меня завтра» — без пересылки писем вручную.
- Вложения агент получает текстом и файлом; файл, которого ещё нет на диске, AIOWA скачивает с сервера по его запросу.
- Только чтение: отправить, удалить, переместить или отметить письмо агент не может; прочитанное им остаётся непрочитанным.
- По умолчанию выключено. Включается в настройках на вкладке «ИИ» → «Доступ для агентов (MCP)»: там же выбор, что можно читать (письма, вложения, календарь, контакты), готовые строки подключения для Claude Code и Claude Desktop и журнал — кто, что и сколько получил. Выключение действует сразу.
- Важно: всё, что агент прочитал, уходит в его модель — обычно облачную. В режиме «Только свои модели» доступ не включается.
