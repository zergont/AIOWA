Первый патч по замечаниям обкатки. С этой версии обновления ставятся из самого приложения.

- Обновление из приложения: в настройках вкладка «О программе» — версия, «Проверить обновления», автоматическая проверка при запуске и раз в сутки, «Установить и перезапустить». Найденная версия показывается строкой внизу окна.
- Один и тот же ящик под разными формами логина открывает одну базу; на вкладке «Данные» видны базы на диске.
- Папки и свежие письма появляются по ходу синхронизации, не дожидаясь её конца.
- Строка списка писем и дерево папок доработаны по замечаниям обкатки.
- Письма в тёмной теме.
