Первый патч по замечаниям обкатки. С этой версии обновления ставятся из самого приложения.

- Обновление из приложения: настройки → «О программе» — версия, «Проверить обновления», автоматическая проверка при запуске и раз в сутки, «Установить и перезапустить». Новая версия показывается строкой внизу окна; если в композере несохранённое письмо, приложение сначала спросит.
- Одна база на ящик: логины вида «savvidi», «savvidi@ngenergo» и «NGENERGO\savvidi» ведут в одну базу. Мастер находит уже скачанную базу этого ящика и предлагает продолжить с ней. Срок в мастере относится только к текстам писем — это теперь написано.
- Настройки → «Данные»: все базы на диске с размером, отметкой текущей, «Открыть папку» и удалением лишних. Размер базы и кэша виден в подсказке строки состояния.
- Синхронизация: папки и письма появляются по ходу загрузки, при первой синхронизации папки сначала приходят свежие письма. Выбор и прокрутка списка при обновлении не сбрасываются.
- Список писем: третья строка с началом текста, значки «удалить», «прочитано», «флаг», «в архив» при наведении, флажок для выбора нескольких писем мышью.
- Свёрнутые папки запоминаются между запусками.
- Тёмная тема: письма показываются в тёмных тонах с сохранением оттенков; на карточке письма можно показать его как задумано, в настройках «Вид» — выбрать светлый лист для всех писем. Печать всегда на белом.
