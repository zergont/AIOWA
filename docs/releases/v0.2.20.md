ИИ-агент читает сканы во вложениях.

- Агент, подключённый к AIOWA, теперь сам читает отсканированные документы: страницы PDF без текста и фотографии документов (JPG, PNG, TIFF, BMP) распознаются на этом компьютере, на русском и английском. Раньше для скана агент получал только путь к файлу.
- Распознавание идёт средствами Windows, без облачных сервисов: содержимое вложений никуда не уходит.
- Текст приходит по страницам, с пометкой, взят он из файла или распознан. В числах, таблицах и под печатями возможны ошибки — об этом агент предупреждён.
- Распознанное запоминается: повторное чтение мгновенное, а письмо начинает находиться поиском по словам из скана.
- Флажок «Распознавать сканы во вложениях» — в настройках, «ИИ» → «Доступ для агентов (MCP)»; по умолчанию включён. После обновления перезапустите агента.
