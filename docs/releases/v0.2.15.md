Вложения можно убрать из пересылаемого письма, вложение из письма перетаскивается в письмо, которое пишете.

- При пересылке у каждого вложения исходного письма теперь есть крестик: убранный файл с письмом не уйдёт. Это работает и когда письмо сохранено черновиком, и когда оно перенесено в отдельное окно.
- Вложение из полученного письма можно перетащить мышью прямо в письмо, которое пишете, например в ответ на это же письмо. Если файл ещё не скачан, AIOWA скачает его сама. Перетащить то же вложение второй раз — копии не будет.
- При первом запуске после обновления база обновляется — это занимает мгновение.
