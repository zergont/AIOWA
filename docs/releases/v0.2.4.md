Контакты Skype для бизнеса в «Людях» и имя отправителя одной строкой.

- «Люди» → «Мои контакты» показывают и список контактов Skype для бизнеса, как «Мои контакты» в OWA: компания, должность, отдел, телефоны и адрес Skype. Эти контакты только для просмотра (их ведёт сам Skype): вместо «Изменить» и «Удалить» — «Добавить в контакты», новый свой контакт с теми же полями. Каждый человек — один раз, даже если Skype хранит его в нескольких своих группах; если он есть и в ваших контактах, показывается ваш контакт.
- Карточка человека из письма отмечает «В контактах Skype» и показывает телефоны из Skype; адреса контактов Skype подсказываются в «Кому» наравне с вашими контактами.
- Имя отправителя в заголовке открытого письма больше не ломается на несколько строк: оно одной строкой (длинное — с многоточием, полностью — в подсказке), а кнопки действий при узкой колонке чтения переходят строкой ниже.
