ИИ-агент видит страницы вложений картинками.

- Агент может посмотреть страницу PDF или картинку во вложении как есть — с печатями, подписями и таблицами, где распознанный текст ошибается.
- За один раз он получает до пяти страниц. Если его приложение картинки из ответов не показывает, AIOWA сохраняет страницы файлами в папку выгрузки, и агент читает их оттуда.
- Флажок «Показывать агенту страницы вложений картинками» — в настройках, «ИИ» → «Доступ для агентов (MCP)»; по умолчанию включён.
- Распознавание сканов теперь читает страницу ровно в 300 точек на дюйм: раньше на экранах с увеличенным масштабом она рисовалась крупнее, чем нужно.
- После обновления перезапустите агента.
