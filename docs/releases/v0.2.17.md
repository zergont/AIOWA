Щелчок по уведомлению о новом письме открывает это письмо.

- Когда AIOWA свёрнута и приходит письмо, щелчок по всплывшему уведомлению Windows разворачивает окно и открывает письмо во «Входящих». По уведомлению «N новых писем» открывается папка, по напоминанию о встрече — эта встреча в календаре.
- Щелчок срабатывает, пока уведомление на экране; из Центра уведомлений Windows письмо пока не открывается.
