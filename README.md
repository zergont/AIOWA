# AIOWA

Оффлайн почтовый клиент для корпоративного Exchange в духе Outlook Web App, с ИИ-слоем: поиск по почте естественным языком и помощник при ответе на письма. Rust, сначала Windows 11.

Проект на стадии концепта, кода пока нет. Все решения, проверенные факты, архитектура и дорожная карта собраны в [CONCEPT.md](CONCEPT.md). Опросник для администраторов Exchange и службы ИБ и другие проработки лежат в [docs/](docs/).
